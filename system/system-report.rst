System Report
=============

In this place you can't configure EasyGo Solutions. Instead you can obtain a system
report about EasyGo Solutions and its configuration.

See the description in EasyGo Solutions for an explanation. You can even find a preview
of the included data below the ``Download`` button.

.. note:: EasyGo Solutions never sends this automatically to anyone. It is a manual
   process only to provide better support based on your configuration.
